# Support Applications

These tools and habits make working on your computer easier. None is required for the course.

## Dictation: speak instead of typing

Dictation is speech-to-text: you speak, and the words appear where you would normally type. It is useful for explaining a problem to an AI or asking for a change to a notebook. You can describe what you want in ordinary language, then review the text before sending it.

[OpenSuperWhisper](https://github.com/Starmel/OpenSuperWhisper) is a dictation app for macOS. Windows also has [built-in voice typing](https://support.microsoft.com/en-us/accessibility/windows/use-voice-typing-to-talk-instead-of-type-on-your-pc).

Text-to-speech is the reverse: the computer reads text aloud. That can also be helpful for reviewing something you have written.

## Git: save versions of your work

Git is version control. It records snapshots of your project so you can see what changed and return to an earlier version. That is particularly useful when an AI is editing your files.

Git can be complicated, but you can ask the AI to handle the commands. Start with:

> Set up Git in this project. Exclude the Python environment, credentials, and large data files, and save an initial snapshot of my work.

Before a substantial change:

> Save a Git snapshot of my current work with the message "before changing the regression".

To review the result:

> Show me what changed since that snapshot and explain it.

Git records versions; GitHub is a separate service for hosting repositories online. You can use Git on your computer without a GitHub account. Local version history is also separate from a backup on another device or service.

## Other useful conveniences

- **Clipboard history.** Retrieve something you copied earlier, such as a command, file path, or error message.
- **Window arrangement.** Keep VS Code and your assignment or reference material visible side by side.
- **Screenshots and screen recordings.** Show an AI or instructor the part of the interface that is confusing you. Include the error text when available.
- **Automatic backups.** Keep a separate copy of your work in case your computer is lost or fails.
- **VS Code conveniences.** Auto Save, word wrap, and the Command Palette can reduce repetitive work. These belong in the shared VS Code guide rather than requiring more applications.
